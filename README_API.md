# YOLO Mouse Detection API

Flask веб-приложение для обработки видео с детекцией мышей с использованием предобученных YOLO моделей.

## Возможности

- 📹 Загрузка видео файлов (MP4, AVI, MOV, MKV, FLV, WMV, WEBM, M4V)
- 🎯 Автоматическое обнаружение доступных предобученных YOLO моделей из папки `runs/detect`
- 🔍 Выбор модели и версии весов (best.pt или last.pt)
- ⚙️ Настройка порога уверенности детекции
- 📊 Обработка видео с рисованием bounding boxes
- 💾 Воспроизведение и скачивание обработанного видео

## Установка

Все необходимые зависимости должны быть уже установлены. Если нет, установите их:

```bash
pip install flask opencv-python ultralytics torch
```

## Запуск

Для запуска приложения выполните:

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## Структура проекта

```
mouse_segmentation/
├── app.py                  # Flask приложение
├── yolo_using.py          # Модуль для работы с YOLO моделями
├── templates/
│   └── index.html         # HTML интерфейс
├── runs/detect/           # Папка с предобученными моделями
│   └── <experiment_name>/
│       └── weights/
│           ├── best.pt
│           └── last.pt
├── uploads/               # Временная папка для загруженных видео (создается автоматически)
└── outputs/               # Папка для обработанных видео (создается автоматически)
```

## Использование

1. Откройте браузер и перейдите на `http://localhost:5000`
2. Выберите предобученную модель из списка (если доступны несколько)
3. Выберите версию весов (best.pt или last.pt)
4. Настройте порог уверенности (0.1 - 1.0)
5. Загрузите видео файл
6. Нажмите "Обработать видео"
7. Дождитесь завершения обработки (может занять некоторое время)
8. Просмотрите результат и при необходимости скачайте обработанное видео

## API Endpoints

### GET /
Главная страница с интерфейсом загрузки видео

### GET /api/models
Получить список доступных моделей

**Response:**
```json
{
  "models": [
    {
      "key": "epm1_finetune3",
      "name": "Epm1 Finetune3",
      "versions": ["best", "last"],
      "default_version": "best"
    }
  ]
}
```

### POST /api/process_video
Обработать загруженное видео

**Request:**
- `video` (file): Видео файл
- `model` (string): Имя модели (ключ)
- `version` (string): Версия весов ("best" или "last")
- `conf_threshold` (float): Порог уверенности (0.1-1.0, по умолчанию 0.25)

**Response:**
```json
{
  "success": true,
  "message": "Видео успешно обработано",
  "output_file": "processed_video.mp4",
  "model": "epm1_finetune3",
  "version": "best"
}
```

### GET /api/video/<filename>
Потоковая передача обработанного видео (для HTML5 video player)

### GET /api/download/<filename>
Скачать обработанное видео

## Примечания

- Обработка видео может занять значительное время в зависимости от длины видео и мощности компьютера
- Рекомендуется использовать GPU для ускорения обработки
- Загруженные видео автоматически удаляются после обработки
- Обработанные видео сохраняются в папке `outputs/`

## Устранение неполадок

### Модели не найдены
Убедитесь, что в папке `runs/detect/` есть подпапки с моделями, содержащие папку `weights/` с файлами `best.pt` или `last.pt`.

### Ошибка при загрузке видео
Проверьте:
- Размер файла не превышает 500MB
- Формат файла поддерживается (MP4, AVI, MOV, MKV, FLV, WMV, WEBM, M4V)
- Файл не поврежден

### Медленная обработка
- Используйте GPU если доступен (автоматически определяется)
- Обрабатывайте видео меньшего размера
- Уменьшите порог уверенности для меньшего количества детекций
